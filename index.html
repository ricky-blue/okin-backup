okin-backup

okin-backup は、自宅サーバー「okin」のバックアップを、機器の故障などに備えて運用者本人の Google ドライブに保管するための個人用アプリです。

バックアップの仕組み

サーバーで作成したバックアップファイルを、運用者が管理する環境から rclone と Google Drive API を使って指定の Google ドライブフォルダに転送します。Google アカウントへのアクセスは、運用者が Google OAuth で許可します。

このサイトはアプリの用途とデータの取り扱いを案内する公開ページです。バックアップの操作やファイルの閲覧は、運用者が管理する環境で行います。
