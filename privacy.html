okin-backup ホーム

プライバシーポリシー

適用開始日 2026年11月7日

この方針は、自宅サーバー「okin」のバックアップを運用者本人の Google ドライブに保管する個人用アプリ「okin-backup」に適用されます。

取り扱うデータと利用目的

Google Drive API を通じて、指定した保存先のバックアップファイルと、保存先やファイルを識別するための情報（フォルダ名、ファイル名、識別子など）を取り扱います。これらの情報は、バックアップの転送、保管、保存状況の確認に使います。Google OAuth のトークンは、許可された Google Drive API に接続するために使います。

保存先とアクセス管理

バックアップの転送先は、運用者本人が管理する Google ドライブの指定フォルダです。運用者は、保存先を公開共有せず、アクセスを本人に限定する方針です。Google OAuth の認証情報は、運用者が管理するローカル環境で取り扱い、公開サイトやリポジトリには掲載しません。

共有・販売・広告利用

バックアップの保存に必要なデータは Google ドライブに送信します。運用者は、バックアップファイル、Google Drive API から取得したデータ、認証情報を他者に公開・提供せず、販売や広告配信、広告のための分析にも利用しません。

保持と削除

Google ドライブ上で直近52世代のバックアップを保持する予定です。52世代は保存するバックアップの数で、保存日数の保証はありません。自動で古い世代を削除する仕組みは運用開始が確認できていないため、削除が必要な場合は運用者が対象を確認し、Google ドライブ上で手動で削除します。ごみ箱に移したファイルは、Google ドライブのごみ箱の扱いに従います。ローカルのコピーは運用者が別途管理します。

アクセス許可の取り消し

運用者は Google アカウントの接続管理から okin-backup のアクセス許可を取り消せます。保存済みファイルの削除は、Google ドライブ上で別途行います。

問い合わせ

データの取り扱いに関する問い合わせ先は、Google OAuth 同意画面に表示されるサポート連絡先です。
